## Tile 视觉规则

| 状态 | 表现 |
|---|---|
| 自己 nativeHalf, `entityId=null` | 半透明己方颜色背景 + 中央显示 type 图标 + 角标价格 |
| 自己 nativeHalf, `entityId≠null` | 实色己方颜色背景 + entity 图标居中 + 顶部 HP bar |
| 敌方 nativeHalf, `isExplored=false` | 灰色背景 + 中央灰色 `?` (type 不可见) |
| 敌方 nativeHalf, `isExplored=true, entityId≠null` | 实色敌方颜色 + entity 图标 + HP bar |
| 敌方 nativeHalf, `isExplored=true, entityId=null` | 实色敌方颜色 + 中央 type 图标 (空着但 type 当前可见) |
| Type = `question` | 黄色 `?` 图标 + 角标 25 |
| 占领后 (owner 变了) | 背景色变成新 owner 颜色, 其他属性保留 |

视野规则定义见 [tiles.md](./tiles.md)。

## Entity 图标 (emoji 占位, 后续可替换 sprite)

- 矛兵 🗡 / 弓手 🏹 / 兵营 🏚 / 防御塔 🏰 / 金矿 ⛏️ / Base 🏛️ / 问号 ❓

---

## Entity HP bar

tile 顶部 2dp 横条，>60% 绿 / 30-60% 黄 / <30% 红。

---

## Base 独立显示

棋盘上下边外各一行单独显示 base 状态（大字 HP/maxHP + 大图标）。直观看到双方主血。

---

## 底部信息条

- 左：金币（大字、黄色、滚动动画）
- 右：4 张卡的当前等级
- Tap 底部条 → 弹卡牌详情浮层 (HP/ATK/产兵周期/产币量 等)

---

## 交互流程

**翻格（建造）**:

1. 玩家 tap 一个 tile
2. sim 同帧判定建造前置条件（见 [tiles.md](./tiles.md)）
3. 通过 → 扣币 + spawn entity + 反馈动画 (150ms tile 闪 + 200ms entity 渐入)
4. 不通过 → 按 [tiles.md](./tiles.md) 翻格反馈规则

**对局开始**: 3-2-1 倒计时浮层（cover 棋盘 1 秒）然后 fade out。

**对局结束**: 全屏胜负界面（大字 "胜利" / "失败" / "平局"）→ "继续" 按钮 → 看是否给箱子 → 主菜单。
