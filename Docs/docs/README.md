# 占城大师 Demo 设计文档

> **目标**: 在 Meta Horizon Worlds（移动端，TypeScript）上做一个核心玩法 demo。
> **参考**: 抖音小游戏《占城大师》。
> **范围**: 单人 vs 简单 AI，3 分钟一局，每局 1 个箱子用于卡牌升级。
> **不在范围**: PvP / 飞行 / 阵营 / 法术 / 领地经营 / 充值 / 排行榜。

---

## 玩法概览

### 核心循环

**对局内（3 分钟硬上限）**

1. 棋盘开局**对半分**：下半盘归玩家，上半盘归 AI。每个 tile 都有**固定类型**（兵营 / 防御 / 金矿 / 问号），玩家**自己半盘的 type 直接可见**，敌方半盘默认隐藏。
2. 双方各有 1 个 base（开局已建造），周期产币。
3. 玩家点击己方领地内的可建造 tile → 扣金币 → 按 tile.type **建造对应建筑**（兵营会随机选 1 个兵种）。
4. 兵营持续产兵；产出的兵自动寻敌、移动、攻击；防御塔 / 金矿 / base 原地不动。
5. 单位走到敌方 tile → 占领该 tile（owner 变己方）。
6. 摧毁敌方 base → 胜利；3 分钟超时 → ownedTiles 多者赢。

**对局后**

7. 给 1 个箱子放入槽位（满 4 槽则不给）。箱子 10 分钟后台自动开，发放金币 + 碎片。
8. 用碎片 + 金币升级卡牌（提升对应兵种 / 建筑的数值 + 产兵 / 产币速度）。

## 不在 demo 范围（明确排除）

- PvP 联机
- 飞行 / 多种地形 / 法术卡
- 阵营（人类 / 兽人 / 亡灵 / 机械）
- 兵种品质分级（demo 所有兵都是 "普通"）
- 同 type 多价格档（兵营 / 防御 / 金矿 都统一 50）
- 卡组构筑（玩家选卡进 deck）
- 多品质箱子 / 钻石加速 / 看广告 / 月卡 / 充值
- 领地经营（放置玩法）
- 段位 / 排行榜 / 锦标赛 / 社交表情
- 音效 / BGM / 粒子（先功能后表现）
- 教程

## 后续扩展（先记着，别现在做）

- **PvP**: `aiDecide` 换成远程玩家 input，`/sim` 不动，新增 `/net` 模块。
- **更多兵种 / 品质**: 加骑士 / 龙 / 治疗，引入"史诗 / 传奇"品质和对应稀有度 tile。
- **同 type 多价格档**: 高价兵营 / 防御 tile 产出更稀有的版本。
- **法术卡**: 加单次性的卡（冰冻 / 火球等）。
- **阵营**: Card 加 `faction`，组合限制。
- **领地经营**: 完全独立子系统，开新 `/territory` 模块。
- **多张卡的 deck-building**: 玩家从拥有的卡里组卡组，影响翻格结果。
- **箱子多品质 + 加速**: 钻石 / 广告加速开箱（IAA 变现入口）。
- **音效 / 反馈 / 美术升级**。
